# Math Mastery 🎉

A fun, interactive math game designed for 5 and 6-year-olds to practice addition and subtraction!

## Features

- **Kid-Friendly Design**: Colorful, engaging interface with large buttons and fun animations
- **Three Game Modes**:
  - ➕ **Addition**: Practice adding numbers (0-10)
  - ➖ **Subtraction**: Practice subtracting numbers (results always positive)
  - 🎲 **Mixed**: Random mix of addition and subtraction problems
- **Visual Helpers**: See the math with fun emoji representations
- **Progress Tracking**: Stars, streaks, and progress bar to motivate learning
- **Positive Feedback**: Encouraging messages and confetti celebrations
- **Help Button**: Visual counting aid when kids need extra support

## How to Play

1. Open `index.html` in a web browser
2. Choose a game mode (Addition, Subtraction, or Mixed)
3. Look at the math problem
4. Click on the correct answer from the four choices
5. Earn stars for correct answers and build your streak!

## Age-Appropriate Design

- Numbers stay small (0-10) for easy counting
- Subtraction always results in positive numbers
- Large, tap-friendly buttons for small fingers
- Visual counting helpers with fun emojis
- Encouraging feedback for all attempts

## Files

- `index.html` - Main game page
- `style.css` - Colorful, kid-friendly styling
- `game.js` - Game logic and interactions

## Running the Game

Simply open `index.html` in any modern web browser. No installation or server required!

```bash
# Or use a simple HTTP server
python -m http.server 8000
# Then visit http://localhost:8000
```
